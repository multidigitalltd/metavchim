# 09 · מפת דרכים

עקרון: כל שלב מסתיים במשהו ש**מתווך אמיתי משתמש בו ומשלם עליו**. לא בונים הכל בבת אחת.

## שלב 0 — תשתית (2–3 שבועות, במקביל לתחילת שלב 1)

- ריפו, CI/CD מלא (כולל סוויטת Cross-Tenant מהיום הראשון), סביבות, IaC.
- שלד Modular Monolith: מבנה מודולים, Event Bus + Outbox, TenantContext + RLS, RBAC, Audit Log.
- Design System בסיסי + שלד PWA RTL נגיש.
- **זה השלב שקובע את איכות כל מה שאחריו — לא מקצרים אותו.**

## שלב 1 — MVP (יעד: 8–10 שבועות אחרי שלב 0)

הבטחת השלב: *"נכס נכנס בקול, קונים מקבלים הצעות בוואטסאפ, כלום לא נשכח."*

| פיצ'ר | היקף |
|-------|------|
| ניהול נכסים | CRUD מלא, מדיה, ציון מוכנות, סטטוסים |
| קליטת נכס בקול | דרך האפליקציה ודרך וואטסאפ; תמלול → חילוץ → כרטיס + חוסרים |
| ניהול קונים | פרופיל מלא, must/nice, בשלות (חישוב בסיסי) |
| ניהול לידים | קליטה ידנית + מוואטסאפ נכנס, ציר זמן, סטטוסים |
| מנוע התאמות | סינון + ניקוד משוקלל + הסבר; דו-כיווני |
| הצעות בוואטסאפ | אישור מתווך → תבנית → דף הצעה → מעקב פתיחות/עניין |
| דשבורד יומי | "מה דורש טיפול" + Next Best Actions |
| תזכורות | למתווך (וואטסאפ + In-App) |
| תשתית עסקית | הרשאות בסיס (Owner/Agent), Onboarding, מסלול Basic/Pro ראשוני |

**קריטריון מעבר**: 5–10 משרדי פיילוט פעילים; מהקלטה להצעה < דקה; שימוש שבועי חוזר.

## שלב 2 — הטלפון (6–8 שבועות)

הבטחת השלב: *"הטלפון שלך לא מפספס יותר לידים."*

- סוכן קולי לשיחות שלא נענו: תסריט סינון, מידע על נכסים, תיאום חזרה, אסקלציה לאדם.
- תמלול + סיכום לכל שיחה (גם של המתווך עצמו, אם ירצה).
- תיאום שיחות ופגישות + סנכרון Google Calendar דו-כיווני.
- פולו-אפ אחרי סיור ("איך היה?") ועדכון סטטוס.
- POC ספקי עברית (STT/TTS) נעשה **בתחילת** השלב — הסיכון הטכני הגדול ביותר במוצר.

**קריטריון מעבר**: >80% שיחות-שלא-נענו מטופלות ע"י הסוכן ללא תלונת לקוח; NPS פיילוט חיובי על הפיצ'ר.

## שלב 3 — הרשת (6–8 שבועות)

הבטחת השלב: *"מרוויחים גם מקונים שאין לך נכס בשבילם."*

- מאגר ביקושים אנונימי בין סוכנויות (שיתוף מבוקר, חשיפה מדורגת, הסכמה כפולה).
- קליטת לידים/ביקושים מ-Kanko (Connector + דה-דופליקציה).
- מערכת קרדיטים מלאה (Ledger, רכישה, תמחור פעולות).
- מסלול Agency: רב-סוכנים, הרשאות מותאמות, מאגר משותף פנימי.

**קריטריון מעבר**: עסקת שיתוף-פעולה ראשונה נסגרת דרך המערכת.

## שלב 4 — העמקה (רציף)

- AI Sales Coach (המלצות יזומות: "4 קונים חמים בלי הצעה השבוע").
- דוחות ביצועים למשרדים; אנליטיקות.
- Webhooks יוצאים + API ציבורי + White-Label (Enterprise).
- אוטומציות מתקדמות (Playbooks: "קונה פתח פעמיים ולא הגיב → הודעת המשך אוטומטית באישור").
- דפי נכס ציבוריים / פיד לאתר השיווקי.
- Connectors נוספים (פורטלים, מקורות לידים).

## סיכונים מרכזיים ומיתונם

| סיכון | מיתון |
|-------|-------|
| איכות STT/TTS בעברית לא מספקת | POC מוקדם (תחילת שלב 2); הסוכן הקולי הוא שלב 2, לא תנאי ל-MVP |
| חסימת/הגבלת וואטסאפ | API רשמי בלבד, תבניות מאושרות, מכסות, ניטור Quality |
| מתווכים לא מאמצים | MVP עם רגע ה"וואו" (נכס בקול → 17 קונים); Onboarding בשעה; פיילוטים צמודים |
| עלויות AI גבוהות מהצפוי | מדידה פר-פעולה מהיום הראשון; מכסות; מודלים מדורגים |
| Scope Creep | כל פיצ'ר חדש נכנס רק לשלב הבא, לא לנוכחי; מסמך זה הוא החוזה |
