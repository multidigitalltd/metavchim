## עקרונות-על (חלים על כל מסמך)

1. **מהירות היא פיצ'ר** — יעד: תגובת API ‏P95 < 300ms, מסך ראשי < 2.5s (LCP), אינטראקציה מיידית.
2. **אבטחה כברירת מחדל** — כל קלט עובר Sanitization, כל פלט Escaping, כל פעולה בודקת הרשאה ושייכות דייר (Tenant), הכל מתועד ב-Audit Log.
3. **מודולריות אמיתית** — כל מודול עם גבול ברור, API פנימי ואירועים. אפשר להוסיף/להחליף מודול בלי לגעת באחרים.
4. **API-First** — כל יכולת קיימת קודם כ-API. הממשק, הוואטסאפ והמובייל הם צרכנים של אותו API.
5. **אנטי-נעילה לספקים** — WhatsApp, טלפוניה, STT, LLM — כולם מאחורי שכבת הפשטה (Adapter) עם ספק ראשי + חלופי.
6. **UX של "מה עכשיו"** — המערכת לא מציגה מידע, היא אומרת מה הפעולה הבאה (Next Best Action).
7. **הכל גם מוואטסאפ** — כל פעולה מרכזית ניתנת לביצוע מתוך שיחת וואטסאפ.
8. **מינימום הקלדה** — קול ובחירה מתוך אפשרויות לפני טפסים.

## מה מחוץ להיקף התכנון הזה

- **האתר השיווקי** — נבנה בנפרד (WordPress, לפי תקן Multi Digital). המערכת חושפת לו API ציבורי מצומצם (למשל דפי נכס) אם יידרש.
- **Kanko** — מערכת חיצונית. נקודת המגע היחידה: קבלת לידים/ביקושים ממנה דרך אינטגרציה חתומה (ראו מסמך 05).
