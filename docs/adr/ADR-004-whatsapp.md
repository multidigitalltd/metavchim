# ADR-004 · WhatsApp: Cloud API רשמי בלבד

**סטטוס:** מוצע · **תאריך:** 2026-07-27

## הקשר
וואטסאפ הוא ערוץ הליבה של המוצר — הצעות, התראות, קליטת נכסים. קיימות ספריות לא-רשמיות (מבוססות WhatsApp Web) זולות יותר לכאורה.

## החלטה
עבודה מול **WhatsApp Business Cloud API הרשמי של Meta** בלבד (ישירות או דרך BSP מוסמך), מאחורי `MessagingProvider` Adapter. ניהול תבניות מאושרות, חלון 24 שעות, Opt-out, וניטור Quality Rating — כחלק מה-Messaging Hub.

## חלופות שנשקלו
- **ספריות לא-רשמיות (Baileys וכו')** — נדחה חד-משמעית: חסימת מספרים = המוצר מת אצל הלקוח; הפרת תנאי שימוש; אין SLA. סיכון קיומי שלא מתקזז בחיסכון.
- **BSP בלבד (Twilio/360dialog) בלי חיבור ישיר** — פתוח: ה-Adapter מאפשר להתחיל עם BSP (Onboarding קל) ולעבור לישיר (עלות נמוכה) בלי שינוי בליבה. ההכרעה הסופית מסחרית, לא ארכיטקטונית.

## השלכות
- (+) יציבות, חוקיות, שרידות המוצר.
- (−) עלות פר-הודעה + משטר תבניות — ממותן ע"י שימוש בחלון 24h לשיחות פעילות ותמחור ההודעות במסלולים.
