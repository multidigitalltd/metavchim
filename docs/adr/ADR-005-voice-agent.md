# ADR-005 · סוכן קולי: פלטפורמה מנוהלת תחילה, הפשטה למעבר עצמי

**סטטוס:** מוצע · **תאריך:** 2026-07-27

## הקשר
הסוכן הקולי (שלב 2) דורש: STT סטרימינג בעברית, LLM עם Tool-Calls, TTS עברי טבעי, והשהיה כוללת < 1.2s. בניית צנרת כזו בעצמנו היא פרויקט הנדסי בפני עצמו.

## החלטה
- שלב 2 נפתח ב-**POC השוואתי** של פלטפורמות Voice-AI מנוהלות (Vapi, Retell, ומקבילות) עם דגש איכות עברית ואינטגרציית SIP ישראלית.
- הפלטפורמה הנבחרת מחוברת דרך מודול `Voice` שמחזיק: תסריט השיחה, הגדרות פר-דייר, Tool-Calls אל ה-API הפנימי (מוגבלי-הרשאה), וכללי אסקלציה. הפלטפורמה מחזיקה רק את צנרת האודיו.
- מעבר עתידי לצנרת עצמית (STT+LLM+TTS ישירות) אפשרי בלי לגעת בליבה — רק מימוש חדש של אותו Interface.

## חלופות שנשקלו
- **בנייה עצמית מיד** — נדחה: חודשים של הנדסת אודיו לפני ערך ללקוח; הסיכון (עברית, השהיה) גבוה. (הסטאק שנבחר ב-ADR-002 — Node — הופך מעבר עתידי לצנרת עצמית לטבעי כשהנפח יצדיק זאת.)
- **בוט IVR קשיח (תפריטים)** — נדחה: הורס את הבטחת המוצר; לקוחות נוטשים.

## השלכות
- (+) זמן-לשוק קצר לפיצ'ר הכי מבודל; סיכון עברית מתגלה ב-POC ולא בהשקה.
- (−) עלות פר-דקה גבוהה יותר — מתומחרת במסלול Pro (דקות כלולות + חיוב עודף); נבחנת מחדש כשנפח השיחות מצדיק צנרת עצמית.
