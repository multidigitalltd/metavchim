# החלטות ארכיטקטוניות (ADRs)

כל החלטה מהותית מתועדת: הקשר → החלטה → חלופות שנשקלו → השלכות.
החלטה משתנה רק עם ADR חדש שמחליף אותה — לא בעריכה שקטה של הישן.

## איך כותבים ADR חדש

1. מעתיקים את המבנה של אחד הקיימים: **הקשר · החלטה · חלופות שנשקלו · השלכות**.
2. שם הקובץ: `ADR-NNN-<נושא-קצר>.md`, מספר רץ.
3. מוסיפים שורה לטבלה כאן, עם סטטוס „מוצע” עד שההחלטה מאושרת.
4. ADR שמחליף קודם מציין זאת בראשו, והישן מקבל סטטוס „הוחלף ב-ADR-NNN”.
