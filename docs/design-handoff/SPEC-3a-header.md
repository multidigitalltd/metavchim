SPEC 3 - Property card: header and overview tab (כרטיס נכס · סקירה)
Reference render: "מתווכים - כרטיס נכס 2026". Read the four DESIGN-SYSTEM files first.

1. BACK LINK
Aligned to the start of the content column, above everything: 15.5px weight 800 in #0B6E35
with a back arrow, reading "חזרה לרשימת הנכסים". On hover it darkens to #08240F.

2. PROPERTY HEADER CARD
One standard card, padding 24px, two rows.

Row 1 holds the property title at 27px weight 900 with letter-spacing -.03em, a status pill
beside it in its domain colour (a draft listing is NEUTRAL, never amber), and a meta line
under the title at 15px in #5E6860 joined by the middle dot, for example
"מימון · נקלט: 25 באוג׳ 2026". Pushed to the end of the row sits the price at 27px weight 900
wrapped in a left-to-right isolate. When the price is empty, print "טרם הוזן מחיר" at 19px
weight 800 in #B4532A with an amber text button that opens the field. When the record does
have a price, no missing-price warning may appear anywhere on this screen.

Row 2 is the action bar: gap 10px, every button 44px high. In order: "מצא לי קונים" as the
green solid primary action, "צור דף נחיתה" green soft, "קבע סיור" outline, "עריכה" outline,
and "מחיקה" outline whose hover state moves into the red-clay domain.
