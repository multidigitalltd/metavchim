# SPEC 4b — Tabs: שיתופי פעולה and בעל הנכס

## 3. שיתופי פעולה — publish to the network, demand from the network

### Section A — "פרסום הנכס לרשת המתווכים"
- Sub line: "עוד עיניים על הנכס הזה — בלי לחשוף את הכתובת ואת הבעלים."
- A green domain panel with two chip groups: what other offices SEE (עיר · חדרים · סוג · טווח מחיר)
  in green, and what stays HIDDEN (כתובת · בעל הנכס · טלפון) in neutral with a lock icon.
- Primary button "פרסום לרשת". Once published the button becomes "הפסקת פרסום" (outline, red-clay
  on hover) and a green pill reads "מפורסם לרשת · 5 משרדים צפו".

### Section B — "ביקושים ברשת"
- Head + purple count pill ("3 קונים").
- Row per network demand: requesting office name + city, the demand summary (חדרים · תקציב · אזור)
  as PURPLE chips, a score tile like SPEC 4a, and buttons "בקשת שיתוף" (green soft) + "פרטים" (outline).
- The commission split is written as text in the row: "עמלה 50 / 50" in dir ltr isolate, purple.
- The whole demand row stays in ONE domain (purple). Do not mix amber into it.

## 4. בעל הנכס — owner, occupant, marketing report

### Section A — "בעל הנכס"
- Empty: "טרם הוזן בעל נכס. בלעדיו אי אפשר לשלוח עדכון שיווק ולא להחתים על בלעדיות."
  + button "הוספת בעל נכס" (green solid).
- Populated: 52px avatar tile with initials, name 19px/900, role 15px #5E6860, then contact rows
  — phone and email in dir ltr isolate, each with a copy icon button.

### Section B — "מי גר בנכס"
- Three radio tiles: "הבעלים גר בנכס" · "אין דייר" · "מושכר".
- Choosing מושכר reveals tenant fields (שם · תום חוזה · תקופת הודעה) in the same soft tile style.
- Both section heads use the identical head pattern — do not let one drift.

### Section C — "דוח פעילות לבעל הנכס"
- Sub line: "ביקורים, פגישות ופניות של מתעניינים בנכס. בלי שמות, בלי מספרי טלפון."
- Four KPI tiles: ביקורים בדף · פניות · סיורים · הצעות, in the neutral and green scale.
- Button "הפקת דוח" (green solid). The report NEVER contains lead identities — say so in the card.
- Empty: "עוד אין מה לדווח" with the button disabled and the reason stated.
