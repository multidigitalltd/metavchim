# הפעלת חיבור עצמאי למתווכים — מדריך Meta שלב אחרי שלב

מה שצריך לעשות **פעם אחת** בפייסבוק כדי שכל מתווך יוכל לחבר את
המספר שלו בשתי דקות. הקוד בצד שלנו כבר קיים ([docs/12](12-whatsapp-coexistence.md));
כאן הצד שאי אפשר לכתוב בקוד.

> **המדריך הזה מניח שהשלמת את [מדריך ההקמה הבסיסי](whatsapp-setup.md)** —
> תיק עסקי, אפליקציה, מוצר WhatsApp, טוקן System User ו-Webhook
> מאומת. אם לא, לשם קודם: השלבים כאן נשענים עליו, ו-App Review
> דורש קו עובד להדגים עליו.

---

## תמונת המצב — למה זה לוקח שבועות ולמה להתחיל היום

מתוך כל מה שכאן, **רק שלב 5 הוא עבודה שלך שנמדדת בדקות.** השאר הוא
המתנה לאישורים של Meta. לכן הסדר הוא: לפתוח את כל מה שדורש אישור
מוקדם ככל האפשר, ולהתעסק בטכני בזמן שהם רצים ברקע.

| שלב | מה זה | כמה זמן |
|---|---|---|
| 1 | אימות עסק | ימים עד שבועיים |
| 2 | Configuration של Embedded Signup | 15 דקות |
| 3 | שדות Webhook נוספים | 5 דקות |
| 4 | App Review — Advanced Access | 3–14 ימים |
| 5 | הזנת שני המזהים אצלנו | 2 דקות |
| 6 | Tech Provider / Access Verification | ימים; **אפשר לפתוח פיילוט לפניו** |

---

## שלב 1 · אימות עסק — אם עוד לא הושלם

`business.facebook.com` ← **Settings** ← **Business verification** ←
**Start verification**.

הכתובת במסמכים חייבת להתאים לכתובת שבתנאי השימוש ובמדיניות הפרטיות
באתר — Meta משווה, ואי-התאמה מחזירה את התהליך להתחלה.

**זה תנאי סף לשלבים 4 ו-6.** בלעדיו אין טעם להתחיל אותם.

---

## שלב 2 · Configuration של Embedded Signup

זה מה שמייצר את ה-`config_id` — המספר שאומר לפופאפ של Meta *איזו*
זרימה לפתוח.

1. `developers.facebook.com` ← האפליקציה שלך
2. בתפריט השמאלי: **Facebook Login for Business** ← **Configurations**
3. **+ Create configuration**
4. **Configuration name** — שם פנימי, למשל `metavchim-onboarding`
5. **Login variation** ← **WhatsApp Embedded Signup**
6. **Assets** — לסמן: **WhatsApp accounts**
7. **Permissions** — לסמן את שלוש אלה:
   - `whatsapp_business_management`
   - `whatsapp_business_messaging`
   - `business_management`
8. **Create** ← להעתיק את ה-**Configuration ID** שמוצג

   > המספר הזה הולך למסך `/platform` בשלב 5. הוא ציבורי (הוא נשלח
   > לדפדפן של המתווך), ולכן אין בעיה לשמור אותו איפה שנוח.

### חשוב — Session Logging

באותו מסך, לוודא ש-**Session logging** מופעל. זה מה שמחזיר לנו את
`waba_id` ו-`phone_number_id` בסיום הזרימה. **בלעדיו החיבור ייכשל
תמיד**, כי הקוד שלנו לא יקבל את המזהים שהוא צריך לשמור.

## שלב 3 · שדות ה-Webhook הנוספים

בלי אלה החיבור עובד "חצי": הודעות נכנסות, אבל ניתוק מהטלפון והדים
של תשובות ידניות לא מגיעים.

**WhatsApp** ← **Configuration** ← ליד *Webhook fields*: **Manage**

לסמן ✓ על כל אלה (`messages` כבר מסומן מהמדריך הקודם):

| שדה | בלעדיו |
|---|---|
| `messages` | שום הודעה לא נכנסת |
| `smb_message_echoes` | תשובה שהמתווך שולח מהטלפון לא נרשמת, והבוט מדבר על גביו |
| `account_update` | מתווך שמנתק מהטלפון נשאר "מחובר" אצלנו לנצח |
| `history` | ההיסטוריה לא מיובאת, והחיבור נתקע ב"מסתנכרן" |
| `smb_app_state_sync` | אנשי קשר לא מסתנכרנים |

## שלב 4 · App Review — Advanced Access

**זה השלב שמעכב הכי הרבה, ולכן להגיש אותו מיד אחרי שלב 3.**

`developers.facebook.com` ← האפליקציה ← **App Review** ←
**Permissions and Features**.

לבקש **Advanced Access** לשלוש ההרשאות משלב 2. לכל אחת צריך:

1. **הסבר במה זה משמש** — לכתוב את מה שהמערכת באמת עושה: פלטפורמת
   CRM למשרדי תיווך שמאפשרת ללקוחות עסקיים לחבר את מספר הוואטסאפ
   העסקי שלהם, לקבל פניות לקוחות כלידים ולהשיב להן.
2. **סרטון הדגמה** — הקלטת מסך שמראה את הזרימה מקצה לקצה: מתווך
   נכנס להגדרות, לוחץ "חבר וואטסאפ ביזנס", עובר את הפופאפ, ואז
   הודעה שנשלחת למספר מופיעה במערכת כליד.

   > **כאן משתלם שהקו שלך כבר עובד.** הסרטון הוא ההוכחה, ואי אפשר
   > לצלם אותו בלי מערכת חיה. זו הסיבה שמדריך ההקמה הבסיסי קודם.

3. **הוראות בדיקה** — משתמש ניסיון וסיסמה שהבודק ב-Meta ייכנס איתם.

**דחייה נפוצה:** הסבר כללי מדי ("ניהול לקוחות"). Meta רוצה לראות
את הקשר הישיר בין ההרשאה למסך. תיאור מדויק חוסך סבב שלם.

אחרי האישור: **App Mode** ← **Live**.

## שלב 5 · שני המזהים אצלנו — וזה הכל

`/platform` ← כרטיס **"וואטסאפ (Meta Cloud API)"** ← החלק
**"חיבור עצמאי של מספרי המשרדים"**:

| שדה | מאיפה לוקחים |
|---|---|
| **App ID** | לוח הבקרה של האפליקציה, למעלה ליד השם |
| **Embedded Signup Configuration ID** | מה שהועתק בשלב 2 |

לשמור. **מרגע זה כפתור "חבר וואטסאפ ביזנס" מופיע אצל כל בעל משרד**
בהגדרות שלו. עד שהם מוזנים הכפתור מוסתר עם הסבר — לא נשבר בלחיצה.

## שלב 6 · Tech Provider ומכסת הקליטה

עד להשלמת האימות הזה אפשר לקלוט **10 לקוחות ב-7 ימים**. זה מספיק
לגמרי לפיילוט — אז **לא לחכות לזה כדי להתחיל.**

`business.facebook.com` ← **Settings** ← **Business assets** ←
**Access Verification** (או דרך WhatsApp Manager ← Account tools).

אחרי האישור המכסה עולה ל-200 לקוחות ב-7 ימים.

## הבדיקה האמיתית — לפני שמזמינים מתווך

לעשות את זה בעצמך, על משרד ניסיון ומספר ניסיון:

1. להיכנס להגדרות של משרד ניסיון ← **וואטסאפ ביזנס** ← **חבר**
2. לעבור את הפופאפ עד הסוף, כולל האישור שמגיע לאפליקציה בטלפון
3. לוודא שהכרטיס מציג את המספר ואת הסטטוס
4. לשלוח הודעה מנייד אחר למספר המחובר ← **אמור להיווצר ליד**
5. **לענות ידנית מהאפליקציה בטלפון** ← התשובה אמורה להופיע בציר
   הזמן של אותו ליד — זו ההוכחה שדו-הקיום עובד
6. לנתק מהמסך, ולוודא שהכרטיס עובר ל"מנותק"

אם שלב 4 עובד ו-5 לא: כמעט תמיד `smb_message_echoes` לא סומן בשלב 3.

## תקלות נפוצות ומה הן אומרות

| מה קורה | הסיבה כמעט תמיד |
|---|---|
| הכפתור לא מופיע אצל המשרד | App ID או Configuration ID לא הוזנו ב-`/platform` |
| הפופאפ נפתח ומיד נסגר | האפליקציה ב-Development ולא ב-Live; או שהמשתמש אינו admin בתיק העסקי |
| החיבור נשמר אבל אין הודעות | ההרשמה ל-Webhooks נכשלה — הכרטיס יראה "החיבור לא הושלם". לחבר מחדש |
| "המספר כבר מחובר למשרד אחר" | בדיוק מה שכתוב — לנתק שם קודם |
| ההיסטוריה נתקעת ב"מסתנכרן" | חלון 24 השעות של Meta נסגר. לנתק ולחבר מחדש |
| הודעות יזומות נכשלות | אין אמצעי תשלום ב-WABA של המתווך. הוא מזין אותו ב-WhatsApp Manager שלו |

## מה שהמתווך עושה — לשליחה אליו

1. נכנס להגדרות ← **וואטסאפ ביזנס**
2. קורא את שלושת הכרטיסים (מה זה נותן, מה מוגבל, מה עולה)
3. לוחץ **חבר וואטסאפ ביזנס**
4. מתחבר עם הפייסבוק שלו, בוחר את המספר העסקי
5. **פותח את WhatsApp Business בטלפון** ומאשר את ההודעה מ-Facebook
   Business, כולל הבחירה אם לשתף היסטוריה
6. מזין את הקוד וסוגר את החלון

תנאים מצידו: המספר פעיל ב-WhatsApp Business לפחות שבוע, והאפליקציה
בגרסה 2.24.17 ומעלה.
